# Design System: LocoRent

## Visual theme

Premium, quiet, white-and-blue accommodation marketplace. Balanced app density, restrained motion, predictable navigation. Prioritize nearby available beds and clear inclusive prices. No marketing splash between customers and search.

## Palette

Canvas #F6F8FB; surface #FFFFFF; primary ink #17243B; secondary ink #65718A; border #E3E9F2; blue accent #3563C1; pale blue #EDF3FF. Statuses use text and icons as well as colour.

## Typography

Manrope with a system sans fallback. Display 32–52px with tight tracking, body 14–16px with 1.6 leading. Numeric prices use tabular figures. No serif typography in dashboards.

## Components

Primary buttons blue with 12px radius; secondary buttons white with thin borders. Inputs have persistent labels and 44px minimum targets. Property cards use 18px rounded photographs, fine borders and almost no shadow. Empty states provide a specific next action. Modal dialogs have accessible names, focus handling and Escape dismissal.

## Layout

Maximum content width 1320px. Desktop navigation rail with spacious main content. Two-column property layout and optional side map. Single-column layouts below 768px; compact bottom navigation on mobile. No horizontal page overflow. Photography is clearly illustrative sample content.

## Interaction

160ms opacity and transform transitions. Visible keyboard focus. Honour reduced motion; no perpetual animation. No neon gradients, emoji icons, overlapping copy, giant promotional hero, or decorative statistics. Preserve user's requested minimal aesthetic over the source skill's more elaborate motion defaults.
