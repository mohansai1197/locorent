# Security and private information

- Keep this repository private; do not commit environment files, tokens, service credentials, private keys, database dumps, customer records, or screenshots containing personal data.
- Supply configuration through local ignored files and hosting/Edge Function environment settings.
- Frontend publishable keys are visible in browser builds. Server secrets must stay on the server.
- Demo login credentials are for publicly shared sample accounts only and must never be reused for private accounts.
- Use no-reply Git author email for commits; avoid copying local Git history that contains personal metadata.
- Before each push, inspect staged files and scan all pushed history for credentials and personal details.
