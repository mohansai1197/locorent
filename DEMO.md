# Presentation demo

Customer `/`, owner `/owner`, and admin `/admin` use separate sample sessions. Demo email addresses follow `<portal>@demo.locorent.test`; configure the shared demonstration password through the variables documented in CONFIGURATION.md. It is intentionally displayed in the demo UI.

Browse without login, sign in as the sample customer, complete fictional name/mobile information once, reserve a sample bed and inspect My bookings. Owners see the saved contact snapshot and booking time. Confirm arrival with the customer's six-digit code. Add a property with room options, amenities and house rules, then review it as admin before it becomes discoverable.

Other walkthroughs: manage offline beds and prices, submit and confirm move-out requests, file complaints, exchange sample messages, and review simulated payouts. All account visitors share the sample workspace. Never enter real customer details or payment information. Admin reset affects every demo visitor.
